## Sobre o Projeto

![Banner][banner]

ConsultaPronta é uma plataforma para triagem, direcionamento e acompanhamento da saúde do paciente, facilitando a comunicação com profissionais de saúde.


## Primeiros passos

### Requisitos

This is an example of how to list things you need to use the software and how to install them.
* Node.js `(24.12.0 ou superior)`

### Instalação

1. Clone o repositório
```sh
git clone https://github.com/consulta-pronta/web.git
```
2. Instale os pacotes NPM necessários
```sh
npm install
```

## Como usar

Para testar o projeto, basta iniciar o servidor de desenvolvimento:
```sh
npm run dev
```
